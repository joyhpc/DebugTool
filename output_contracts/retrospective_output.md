## Skill-Level Learning Requirement

State whether the solved case should change any reusable DebugTool behavior:

- input-cleaning rule;
- routing rule;
- link-model asset;
- probability or cost prior;
- output contract;
- evidence-audit check;
- regression fixture.

If no skill-level change is warranted, say so explicitly and explain why the case remains target-specific.
